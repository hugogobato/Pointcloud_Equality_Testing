# Phase 3 implementation and calibration note

Phase 3's estimator and calibration layer is implemented in
`tda2s/tests/dr_outcome.py`. The AIPW estimate remains delegated to
`tcda_uq.estimators.cross_fit`, including its function-on-scalar outcome
regressions, propensity model, cross-fitting, and per-unit scores. The new
layer reconstructs the out-of-fold predictions once from the returned fold
objects and checks that the cached score tensor agrees with `tcda_uq` to
numerical precision.

The primary statistic is the shared-degree max-over-scale sup norm,
`sqrt(n) max_d sup_t |psi_hat_d(t)|`. The implementation also exposes raw L2,
studentized sup, and studentized L2 diagnostics, positivity and effective
sample-size diagnostics, a sup-norm equivalence decision, and a propensity
learner grid. The double-robustness driver uses a nine-term oracle outcome
model and deliberately misspecifies the Fourier basis and/or the two
propensity interactions.

Degree multiplicity currently has explicit Bonferroni and shared max-statistic
calibrations. The Vejdemo-Johansson--Mukherjee persistence-specific benchmark
is left as a separate comparator rather than being silently approximated by
one of those two procedures.

The unresolved Phase 2 calibration issue is handled by a cached,
vectorized, covariate-preserving permutation path. It permutes labels only
within supplied propensity strata and evaluates the AIPW score with fixed
out-of-fold nuisances. Thus 40 permutations no longer mean 40 fits. This is
finite-sample exact only when the nuisance fits and strata are fixed
independently of the permuted labels, such as a sharp conditional null with
externally fixed design information. With estimated label-dependent nuisances
it is a fast cross-fitted calibration approximation, and the code reports that
scope explicitly rather than claiming exactness.

The long experiments are in `experiments/phase3_dr_calibration.py`. The
oracle functional fleet covers `n in {50, 100, 200, 500}`, three propensity
regimes, null and alternative outcomes, and 500 replications per cell. The
point-cloud, learner, and double-robustness runs are separate designs. The
self-contained Colab fleets are generated by
`experiments/colab/make_phase3_notebooks.py` and download one JSON checkpoint
per shard.

The local checks passed the cached-fit invariants, shared-multiplier
reproducibility, strata-count preservation, positivity diagnostics, and
oracle smoke path. A small local null feasibility run also reproduces the
known sensitivity of finite-sample rejection rates to `n` and statistic form;
it is intentionally not treated as a Phase 3 gate because it has far fewer
than 500 replications. The Phase 3 size gate remains pending the Colab fleet
aggregation.
